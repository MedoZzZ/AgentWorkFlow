# Reusable project workflow framework

Copy the `workflow` folder into a new or existing project, open that project in a new chat, and follow [workflow/START-HERE.md](workflow/START-HERE.md).

This framework includes requirements, use cases, design, architecture, numbered task handoffs, progress tracking, independent verification, repair loops, and user review. Architecture and design are discussed before application implementation.

This directory is the reusable starter, not an application project. Antigravity CLI passed a read-only connection and workspace-reading test; implementation and test execution permissions still need verification. See workflow/CONNECTION-TEST.md.
